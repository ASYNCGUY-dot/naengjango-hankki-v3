# KAMIS 재료비 범위·정확도 측정 (2026-10-18)

외부 검토 인계서(2026-10-15) 작업 E의 산출물이다. 공모전 초안과 PROJECT_REPORT_V3.md의 전후 비교
수치를 **같은 조건으로 다시 낼 수 있게** 원자료와 조건을 남긴다.

- `results.json` — 측정 조건(시세·데이터셋·코드 버전)과 버전별 결과
- `sample.csv` — 위험 유형별 정확도 표본 94건과 1차 판정
- 측정 스크립트 — [`scripts/measure_kamis_coverage.py`](../../../scripts/measure_kamis_coverage.py)

## 다시 내는 법

```bash
./.venv/Scripts/python.exe scripts/measure_kamis_coverage.py --snapshot data/kamis_snapshots/2026-10-18.json --ref fe1c6e6 --ref d7fcee3 --legacy-ref 6b6cd3a~1 --legacy-date 2026-10-16 --sample 20 --out docs/evidence/2026-10-18_kamis_coverage
```

`.env`의 `POSTGRES_URL`(운영 DB, 읽기 전용으로만 연다)과 KAMIS 인증값이 필요하다. 시세 스냅샷
`data/kamis_snapshots/2026-10-18.json`은 저장소에 없다 - KAMIS 자료의 공개 재배포 조건을 확인하지
못해서다. 같은 스냅샷인지는 아래 sha256으로 대조한다. 스냅샷이 없으면 `--save-snapshot`으로 그날
시세를 새로 받는데, 그러면 **다른 날 시세로 잰 다른 측정**이다. 10월 18일 결과를 재현했다고 쓰지 않는다.

의심 5건은 적양배추(양배추 시세), 낙지(수입 냉동 시세뿐), 원본 텍스트가 합쳐진 행 2건, 이름만으로는
소·돼지를 알 수 없는 "안심"이다. 과잉 제외 1건은 원본 텍스트가 잘린 "호두(각"이다. 각 행의 이유는
`sample.csv`에 있다.

**이 표본으로 처음 판정했을 때는 확실한 오류가 있었다.** 그것을 고친 뒤 다시 뽑은 것이 위 표다.

- 한 글자 이름이 다른 이름 안에 들어 있다는 이유로 붙었다: 밤(16행)이 고구마 품종 "밤"에, 마(12행)가
  방울토마토에, 조(좁쌀)가 조기에. 한 글자는 이름이 같은 품목만 후보로 남긴다
- 미니양배추·방울양배추(방울다다기양배추)에 양배추 시세가 붙었다
- "돼지고기(불고기용)"·"(다짐육)"을 부위로 읽어 뺐다. 용도·형태라 대표값으로 본다
- "콩(백태"·"콩(대두"(= 흰 콩), "돼지고기(전지)"(= 앞다리)를 다른 부위로 뺐다

## 한계

- **1차 판정은 사람이 아니라 Claude가 했다.** `판정(사람)` 칸을 사람이 채워야 정확도로 쓸 수 있다
- 표본은 서로 다른 쌍을 뽑은 것이라 **등장 횟수로 가중한 정확도가 아니다.** 자주 나오는 재료(당근
  226행, 우유 105행)와 한 번 나오는 재료가 같은 무게다
- 대표값이 실제로 쓴 부위·품종과 얼마나 다른지는 재지 않았다
- 응답 시간은 다시 재지 않았다. 문서의 11.6초→5.7초는 2026-10-01의 **각 1회** 측정이다
