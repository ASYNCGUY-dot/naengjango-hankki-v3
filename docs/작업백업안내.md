# 집밥 피드와 테마 전체보기 작업 백업

2026년 10월 20일까지 진행한 로컬 작업을 보관한 백업이다.

## 포함한 작업

- 집밥 피드 디자인, 로그인·가입 및 주요 화면 개편
- 키보드 초점, 오류·재시도 안내, 작은 화면·큰 글씨·가로 화면 레이아웃 보완
- 홈 테마의 전체보기와 20개씩 더 보기, 상세에서 돌아왔을 때 목록 복원
- 테마 조회 API의 선택 테마·시작 위치 지원과 API 명세·타입 갱신
- 디자인 시안 여섯 개, 원본 이미지와 미리보기 구성 스크립트

## 검증 결과

- 프론트 테스트 408개 통과, lint 및 빌드 통과
- Python 테스트 787개 통과
- 별도 PostgreSQL 테스트 환경이 필요한 16개는 환경 미설정으로 건너뜀
- 예시 데이터 218개를 브라우저에서 끝까지 중복 없이 열람
- 모바일 320px, 큰 글씨, 글자 간격 확대, 가로 화면 및 데스크톱 가로 넘침 확인
- 테스트는 운영 DB와 분리된 데이터로 실행

## 실행과 서버 반영

프론트 실행·API 연결 방법은 `frontend/README.md`를 따른다.
테마 전체보기는 API 서버에도 이번 `theme`·`offset` 조회 변경이 반영되어야 동작한다.
이 백업을 올리는 작업은 운영 서버 배포를 포함하지 않는다.

비밀 설정, DB, 가상환경, 설치 패키지, 빌드 산출물은 포함하지 않았다.
다른 PC에서는 필요한 환경 설정과 의존성을 별도로 준비해야 한다.

디자인 시안은 `design/시안/냉장고한끼-미리보기.html`에서 확인할 수 있다.
다시 조합하려면 Pillow가 설치된 Python으로 다음 명령을 실행한다.

```powershell
python design/시안/시안-구성.py
```

`--output` 인자로 저장 위치를 지정할 수 있다. 기본 출력은 시안 폴더 안의 미리보기 파일이다.
